# CodeAlpha AI Chatbot

A Java-based AI Chatbot developed as part of the CodeAlpha Java Programming Internship.

## Project Description

This project is an interactive chatbot developed using Java. It uses basic Natural Language Processing (NLP) techniques and a rule-based response system to understand user messages and provide appropriate responses.

The chatbot also provides a graphical user interface (GUI) using Java Swing for real-time interaction.

## Features

- Interactive chatbot communication
- Text normalization
- Basic tokenization
- Keyword-based matching
- Rule-based responses
- Java-related responses
- Study-related responses
- Greeting and general conversation support
- Graphical User Interface using Java Swing
- Send button and Enter-key support
- Exit/Bye command

## NLP Techniques Used

1. Text Normalization
   - Converts user input to lowercase
   - Removes unnecessary punctuation

2. Tokenization
   - Breaks user input into individual words

3. Keyword Matching
   - Identifies important words in the user's message
   - Selects an appropriate response based on detected keywords

## Technologies Used

- Java
- Java Swing
- Java Scanner
- String Processing
- Collections Framework
